# <:soup:1267876748855611392> Soup Command Help
The ${cmd:soup} command can be used to call up any of the server's past themes. By default, it will reply with a random theme. Using arguments allows you to pull up a specific theme.
### Years
By adding a year after ${cmd:soup} like `2022` or `2024`, you'll see a list of all of the server themes from that year. Select any of them to call up the cooresponding theme.
### Other
This argument has two options: `current`, which brings up whatever the current server theme is, and `random`, which returns a random theme (the same as no arguments).
