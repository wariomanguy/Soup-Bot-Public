# :loudspeaker: About Help
The <#ANNOUCEMENTS> channel can be used for making announcements on the server. This channel has a 2 hour cooldown for messages to ensure that annoucements won't get buried.

### Announcement Threads
A thread is automatically created by Soup Bot for messages posted in <#ANNOUCEMENTS>. These threads will automatically take the name of any heading used at the start of your message (example: `# This is a Heading`). Smaller heading styles (`##` and `###`) also work, so long as they are at the start of the message. If you choose not to include a heading, your announcement will be titled "(username)'s Announcement" instead.
