# Leaving Community Notes
You can leave anonymous Community Note posts on server messages to fact-check or add important context. To do so, right-click (or long-press on mobile) on a message and select **Apps** → **Soup Bot** → **Leave Community Note**. From there you will be guided through steps to post your note underneath the message.
## Note Types
There are two types of notes that can be left under a message:
### 👥 Community Notes
These notes are intended for messages that to be fact-checked or could benefit from additional context. When selecting this note type, you will be prompted to input your own note with text and sources.
### 💢 Potential Ragebait
Sometimes, a message can be unproductive or detrimental to discourse. When this happens, you can post a customizable ragebait warning cautioning other Soup members to be mindful when interacting with the message.
