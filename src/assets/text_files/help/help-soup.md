# Soup Help
You can type "help" in front of the command name to learn about how to use it (example: to see help for the `!act` command, type `!help act`. For a Soup Bot command like ${cmd:soup}, type ${cmd:help}`soup`).

There are also some additional help commands associated with roles and mechanics on the server:
### :grey_question: Help with Mechanics:
:grey_question: ${cmd:help}
<:soup:1267876748855611392> `!help essence`
:grey_exclamation: `!help act`
`!help soup officers`
`!help oh`
### :grey_question: Help with Roles:
